WHAT YOU MUST DO FOR CUSTOM HOSTNAMES
  Cloudflare shows "CNAME record not set" until DNS points at Pages. The API token used here
  cannot see a Zone for annahileman.com in this account — DNS may still be at the old host or
  another Cloudflare account. Do ONE of the following:

  A) Use Cloudflare for DNS (recommended)
     - Add the annahileman.com zone to this same Cloudflare account (or use the account that
       already has the domain), then add the exact records shown in:
       Workers & Pages → each project → Custom domains → [domain] → Configure DNS
     Typical pattern:
       staging  CNAME  annahileman-staging.pages.dev   (proxy optional; often DNS only for Pages)
       www      CNAME  annahileman.pages.dev
     Apex (annahileman.com) often uses a flattened CNAME or the target Pages gives you — follow
     the dashboard wizard.

  B) Keep DNS at your current registrar
     - Add the same CNAME / apex records there using the hostnames Cloudflare lists for each
       custom domain (often *.pages.dev targets).

  After records propagate, SSL on custom domains will finish (can take up to an hour).
